# Phoenix Attractions
A small trip planner for exploring a few Phoenix-area spots (a hike, a garden, and a taco place), with photos, hours, cost, and pet-friendly info. Visitors can add attractions to a 'My Trip' list.
## Features
- Browse attractions with photos, hours, cost, and location
- Visit official website of each attraction
- See which spots are pet-friendly
- Add attractions to a 'My Trip' list
## Built With
- HTML with semantic structure (header, main, article, section)
- CSS with Flexbox, responsive layout using flex-wrap, Google Fonts, and a desert color palette
- JavaScript DOM manipulation: a forEach loop adds a click listener to each button, reads the attraction name from a data- attribute, and creates a new list item
